## How Macro Toolworks Professional Sits

Macro Toolworks Professional does not replace the apps you already run. It sits beside them as a named script desk for a Macro Toolworks Professional macro set you keep on a PC you own.

If two people share a PC, each keeps a Macro Toolworks Professional task list of their own. Extra hotkeys wait for their own title instead of crowding the live set.

A first visit should be one short macro you already use, then the same Macro Toolworks Professional script desk the next day. That is enough to see if the layout holds.

Work stays on your own desktop. Scattered hotkeys from other jobs wait off the live list.
